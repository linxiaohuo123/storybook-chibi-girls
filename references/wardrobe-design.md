# 穿搭结构、细节与杂线控制

幻想可以夸张，衣服仍应能穿、能扣、能活动。先设计剪裁与层次，再加装饰。简单任务不必输出长表；内部完成以下检查即可。

## 六项穿搭说明

| 项目 | 必须能解释的关系 |
| --- | --- |
| 内层 | 领口、肩部与袖子属于哪件衣服；不重复长出第二套袖口 |
| 主衣 | 连衣裙、背带短装、短袍或上衣下装的连接；腰线与裙／裤结构连续 |
| 外层 | 披肩、外套、罩裙覆盖哪里，手臂从哪里伸出；通过扣、肩缝或腰带固定 |
| 固定点 | 帽饰、胸针、背带、腰扣、包带、链条、流苏的起点、终点与受力位置 |
| 鞋袜 | 与整体服装体系及活动匹配；成对一致，脚踝与鞋口衔接清楚 |
| 持物 | 手托底、握柄、扶边或转旋钮的具体接触；道具不穿掌、袖口不遮手 |

外层不必每张都有。每组可以安排无披肩、无帽、短外套、分腿短装等角色；不要用固定六件套制造所有人相同的轮廓。

镂空道具显示实际后方的衣服、皮肤、头发或背景，不能一律填白。需要露出白背景时先把孔洞放在身体外侧，再检查短手臂是否够得着、手如何托握。耳侧或脸旁同时有道具、头发与配饰时，指定发束如何避让，避免三者混成一团。

## 将主题变成剪裁

先选一个主题形状，再用真实衣片承载它。例如石榴萼形兜帽、书页形前裙片、贝壳扇形肩领、云形短云肩。让扣件和道具复用同一种形状；不要直接把水果、整座建筑或复杂装置堆到头上。

同一套衣服保持材料和活动逻辑：轻薄袖配较轻配件；夸张厚裙与帽饰有可理解的支撑；短手臂需要摸得到道具。混搭可以有意为之，但须说明连接与比例，不能只是堆类别。

## 用层级做精致

`detail_hierarchy` 明确三项：一个主焦点、少量呼应区域、安静区域。主焦点可以在头饰或胸腰，不强制永远是手持物。

- **轮廓层**：帽沿、领形、肩型、裙片或裤脚。优先保证这层独特且完整。
- **结构层**：缝边、扣合、包边、合乎受力的少量褶皱。用轮廓与平面拼色区分前后层，不用阴影。
- **装饰层**：有限的刺绣、蕾丝、扣件和滚边，围绕同一主题形状。不能把装饰线画成另一套不明衣边。

精细版本可增加装饰层的质量与完整性，不自动增加无数重复小物。不要同时在脸旁、胸口、双手、裙摆、鞋面都安排同等密集焦点。

## 逐部位清线

| 区域 | 常见失败 | 保留什么 |
| --- | --- | --- |
| 袖口 | 蕾丝边、褶线、系带混成三套轮廓；线伸出布面 | 一条明确袖口边、有限褶皱、真正连接的结 |
| 头发与帽饰 | 两套帽沿、发丝穿配件、白亮条 | 头发大形与必要分束、清楚帽饰固定 |
| 领口和肩部 | 披肩无固定点、衣领接错袖子、颈部重线 | 领口归属、肩缝、一个有效扣合 |
| 手与道具 | 把手穿掌、手指多出、物体悬空 | 明确托／握／扶的接触，清楚腕部 |
| 腰带与包链 | 没有端点、从人体中穿出、方向矛盾 | 可见固定点与合理遮挡次序 |
| 裙摆与鞋 | 花边变毛边、多余飘线、鞋底与投影混合 | 分层裙边、必要图案、完整鞋底，无脚下阴影 |

不是所有结构线都必须闭合；眉毛、褶皱、发束线允许自然收笔。清线不能把高细节款整体改成简笔画。没有实际看到缺陷时不编造部位。
