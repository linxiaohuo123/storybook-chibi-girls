# 固定画风下的多种服装方向

这些是可组合的造型方向，不是强制预设或客户已通过样式。选中一个作为组内主语言，必要时混入一个辅助元素；不要一次把全部方向塞进提示词。

## 先区分两个层次

**画风固定项**：约 2～2.5 头身、圆润五官语言、细棕色线稿、头发均匀平涂、干净 2D 色块、单人全身、纯白无影。沿用用户已认可的参考，不能为了换样式随意切成粗描边、3D 或写实。

**造型变化项**：头饰高度、肩部形状、主衣剪裁、裙摆／裤装轮廓、面料形状语言、纹样、道具功能、主辅色与动作。少女角色可以穿符合主题的短裤或分腿式小礼服，不要把女性角色等同于只能穿同一款蓬裙。

## 系列规划的实际检查

1. 同组固定一套五官、线条和细节语言；成员不要全部同一眼型、闭眼笑或双手捧物。
2. 看整组外轮廓：圆帽、尖角帽、兜帽、裸头发饰可以变化；短发、编发、盘发和卷发按组合理分配。
3. 看肩、腰、裙摆或裤脚：如果都一样，只换颜色依然是撞款。换服装组合或姿势，别只换配件。
4. 同一主色关系可以通过面积变化形成系列，不要求所有人的同一部位一模一样。
5. 用户明确要不同绘制画风时，为每组另建画风锚点并各自试样；头发平涂、白底等未被用户修改的要求仍保持。

组级语言是一组选项，不是一名角色要同时穿的衣服。将角色卡编成提示词时，只保留本角色实际选定的衣物、相关形状语言和固定关系；不能把“短袍、短袄、比甲、裤装、罩裙”等整列照搬到一张图里。
