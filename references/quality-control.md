# 质量检查与修复

## 检查依据

检查实际返回图片，而非请求内容。使用 `passed`、`failed`、`not_reviewed` 区分结果。无法判断的维度记为待检查；不把“未发现”写成自动证明“不存在”。先按本次用户要求确定适用检查：仅改颜色且保留原竖幅时，不用默认方图规则判失败；保留的原有缺陷应列明，不声称全图符合默认规范。

先按正常观看尺寸检查整体，再按实际分辨率放大头发、帽饰、手与道具、袖口、裙摆、鞋底；不要用生成式放大改变被检查的证据。

## 默认验收项目

| 项目 | 查看内容 | 失败时处理 |
| --- | --- | --- |
| 文件与构图 | 正方形、一个角色、头饰道具和脚完整、留白正常 | 重新构图，不拉伸或硬裁人物 |
| 角色设定 | 女性、大头短身、无第二人物、身份主题可读 | 修复不符任务的角色或主题 |
| 背景 | 纯白，无边框、文字、编号、背景道具与场景 | 只去背景干扰，保持角色 |
| 头发 | 均匀平涂，无亮带、渐变、镜面反光、塑形暗面 | 用原基底色去光影，保留发束 |
| 无白边和影子 | 无贴纸光边、接地灰椭圆、投影、环境遮蔽 | 定向去除，不削鞋底和白色衣物 |
| 线条 | 无漂浮杂线、双描边、乱穿插、无附着丝带或密集排线 | 列出具体位置后修复 |
| 表情 | 正向自然；批次中眼嘴与头部倾向有变化 | 修表情，保持身份 |
| 结构 | 手指与接触关系合理，道具不融手，衣边与配件连贯 | 单独修局部结构 |
| 配色 | 主辅可分、清晰不灰，无一团深色或到处抢眼 | 按部位改色，不换造型 |
| 差异 | 本批次及真实可读历史中的发型、服装轮廓、姿态有实质变化 | 改新角色卡，不能只改词或色号 |

默认强制项明显失败时，整张不能标记通过；不存在总体高分抵消头发高光或脚被裁掉的规则。审美判断描述可见现象，不声称“已计算出好看”。

## 文件事实检查脚本

当前工具已经提供可访问本地图片时，可运行：

```bash
python3 scripts/check_image.py /absolute/path/image.png
```

依赖 Pillow。脚本读取尺寸、透明度、边带近白比例、非白内容包围盒；**不改像素**。阈值是启发式，压缩、浅色衣物、细线与裁切均可能导致误报或漏报。

- 正方形只证明宽高相同，不证明人物完整。
- 脚本按新图默认规范筛查。编辑任务若明确保留非方形原图，`not_square` 是文件事实，不代表本次改色失败；须对照本次实际任务解释结果。
- 不透明只证明 alpha，不证明白背景。
- 边带近白只描述边带，不证明人物附近无影子或整片背景纯白。
- 非白包围盒不区分人物、编号、阴影或背景物。
- 脚本不识别性别、表情、主题、杂线、好看与否；始终要求视觉检查。
- 无本地文件、Pillow 不可用或无法运行时用可用视觉检查，并说明没有像素证据；不要编造检查输出。

`scripts/check_diversity.py` 只比较角色卡的规范化字符串，不判断真实图像相似性。主题换名、近义发型、姿态近义词仍需人工判断。历史不存在不能当成完成跨会话去重。

## 修复预算

首次生成后最多 2 次定向修复，每次只处理具体失败项并重申保持项。不要不断改随机提示词无限重抽。

首张持续不满足同类硬条件时停止扩大批次并报告缺陷；某张修复未通过则标明，并交代完成与待处理数量。不要把失败稿写入已接受历史。

## 状态记录

仅记录真实可确认的信息，例如：

```json
{
  "quality_status": "not_reviewed",
  "pixel_check": "unavailable",
  "visual_review": "not_reviewed",
  "known_issues": [],
  "repairs_used": 0
}
```

检查后改为实际结果，在 `known_issues` 写出可见问题。未检查时的空数组不代表没有缺陷。实际图片可看且全部适用强制项通过后，才可将 `quality_status` 标为 `passed`。

## 精确白底像素检查与可选归一化

近白边缘不等于精确 `#FFFFFF`。当图片文件可访问且用户要求字面纯白时，运行 `scripts/check_image.py INPUT --require-exact-white-border`。该检查只覆盖外圈边带，不能证明画面其他背景区域也完全纯白。若外部背景近白且连通，可执行 `scripts/normalize_white_background.py INPUT OUTPUT`，仅将从边缘可连通的近白中性色区域归一化为白色，然后人工复核并重跑检查。不要全局替换近白色，否则可能损坏眼睛、蕾丝、衣服和道具。保留原文件，不把此脚本当作自动发丝或线稿质量验证。
