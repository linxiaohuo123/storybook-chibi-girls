# 配色设计

以下是本技能的创作规则与候选色组，不是经实验证明的审美公式。按实际角色检查；色号只引导目标色，不保证生成像素精确等于色号。

## 先分配颜色到部位

每个角色写清楚头发、主服装、辅助布片、浅色缓冲、主道具、点缀、线稿。让帽饰、衣服与道具复用主题色，避免每件小饰品新增一个不相关颜色。

对衣服与配饰的大面积色块，可从“主色约 50%、辅助色约 30%、浅色缓冲约 15%、点缀约 5%”开始设计；比例只是初始预算，排除白背景、肤色、眼睛、头发与线稿，不能用整张图直方图倒推审美合格。

1. 给角色一个明确的主色关系，例如珊瑚橙与雾蓝，而非所有颜色同样醒目。
2. 至少安排一种明亮干净的浅色连接各部位，避免大面积高纯度颜色相邻争夺注意。
3. 让头发与领口、帽子与刘海、手与道具在明度或色相上可区分；不要把头发、披风、裙子与袜子全部画成深色。
4. 用一个冷暖呼应或同色系变化增加丰富度；不要把“柔和”处理成灰蒙蒙，也不要全部漂白成接近白色。
5. 深色可用于发色、小背心或鞋子，周围配置较亮色。默认避免大面积纯黑，不禁止所有深色发型。
6. 保持脸与眼睛的焦点，细碎亮点不能比脸更抢眼。

## 批量的色彩安排

先选本组的主色关系，再给不同成员安排主辅面积。避免全部“浅发＋奶油裙＋同色小披肩”；可让某成员主色在裙身，另一成员主色在外套，浅色仅留给内搭与饰边。背景始终纯白。

内部可比较 2～3 套部位方案，再选一套出图；不因此额外生成三张、也不强制向用户提问。按下列关系筛选，而不是凭色卡名称或整图饱和度打分：

- 帽饰与头发相接时能否区分；深发旁用较亮领口或外衣，不给头发加高光。
- 手与主道具、袖口与道具边界是否粘连；不要让肤色、木色和米色全部挤在一个动作焦点。
- 主衣与外搭是否有清楚的大小色块；小面积强调色是否抢过脸。
- 灰调要保留清楚色相，浅色要保留轮廓；深色可以存在，但不让头发、帽子、披风、袜鞋连成重块。
- 从本批次整体检查冷暖、深浅和发色分布。颜色丰富来自主辅关系和部位变化，不要求每张使用很多独立色相。

只改配色时先定位实际问题并记录保持项，不把配色迭代变成重设计服装。没有看到图片时给方案，不声称已修好实际色块。

## 诊断与定向修复

| 实际问题 | 修改动作 | 保持项 |
| --- | --- | --- |
| 头发、帽子、披风聚成深色块 | 提亮主衣或帽子大面积色，保留一个深色锚点 | 轮廓、主题、姿态 |
| 所有颜色相近而发灰 | 保持柔和基底，恢复清晰主色和小面积冷暖对照 | 细节数量与线稿 |
| 各部位都鲜亮、杂乱 | 缩减独立色相，把次要配件归入主辅色 | 主题道具与结构 |
| 颜色太淡、轮廓融进白底 | 增加局部色相或明度区别，保持干净细线 | 白背景，不添加投影 |
| 头发与衣服颜色糊在一起 | 调整其中一者色相或明度，不靠高光塑形 | 头发平涂 |

不要给整图统一套低饱和滤镜，不用“换成粉色就好看”作为通用解法。用户只改配色时，不增加饰品、换脸、改发型或改变姿态。
