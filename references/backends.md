# 生图后端与能力边界

## 内置生图（默认）

使用当前环境实际提供的图像生成工具；有 `imagegen` 技能时遵守它的调用规则。本技能提供创作和检查流程，本身不是训练后的图像模型，也不提供独立推理服务。

- 默认直接生图，不要求用户提供 API Key。
- 生成与编辑使用当前工具支持的参数。方形、纯白等写入提示词；工具确实有尺寸参数时再设置。不能假装提示词保证实际像素大小。
- 运行时先检查实际工具 schema。当前 ChatGPT 暴露的是 `image_gen.text2im`，而非 `image_gen.imagegen`；`prompt` 参数已弃用，应传 null，图像要求由当前对话确定。仅在支持时传 `transparent_background: false`，不要编造 `referenced_image_paths`、`num_last_images_to_include` 等当前未提供的字段。
- Skill 附带的参考图可用于阅读和设计分析，但不会自动注入生图调用。只有工具真正支持并接受引用时才能宣称已作为图像参考输入；否则使用当前对话的用户参考图与文字化风格规范。
- 新建且无参考时不传参考参数。有风格参考时明确生成新角色而非照抄身份；编辑时明确修改目标与保持项。
- 一个角色一张图、一次调用；多张分别调用，不以大拼图冒充批量独立图片。
- 遵守当前环境展示、保存与访问规则；已自动展示和保存的图，不为获取路径额外下载或重新上传。可看图就先视觉检查，像素检查不可用如实记录。
- 工具失败时明确失败，不捏造图片，不用 SVG 占位替代插画，不自动转付费外部接口。

## 用户明确选择自己的 API 时

先完成角色卡、部位配色与提示词。再按实际接口文档或已配置客户端确认：完整接口地址、模型标识、鉴权、生成/编辑能力、参考图输入方式、允许尺寸、返回字段、轮询与费用约束。

不要从“New API”“OpenAI 兼容”“image2.6”“ima 2.6”等名称推断真实模型 ID，也不要假设 `/images/generations`、`/images/edits`、`response_format`、`negative_prompt` 或 `seed` 必然存在。以文档、schema 和实际响应为准。

密钥由环境变量或现有安全配置读取；不要求在对话粘贴完整密钥，不写进 SKILL.md、提示词、日志或示例。没有配置时仍可交付完整提示词，清楚说明未接通外部后端，不能声称端到端测试通过。

已指定外部接口时不悄悄改用内置模型。超时不代表上游未生成，先查实际任务状态，不无条件重试非幂等付费请求。核实当前文档，不硬编码未经验证的参数。

## 本版本范围

实现内置生图默认流程、外部接口的参数确认边界、纯提示词模式、局部修改、角色卡与质量检查。**不包含也不声称已验证用户私有 New API 的网络、鉴权或模型兼容性**。接入时复用已验证客户端；只有 URL 和别名而没有有效调用证据，仍属数据不足。
