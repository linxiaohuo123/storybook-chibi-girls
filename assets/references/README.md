# 参考图来源与用途

本目录包含此前用于该技能的四张用户参考图。PNG／JPEG 为原始分辨率文件；WebP 是早期缩略预览，保留以兼容旧链接，不用于精细线条验收。

| 原始文件 | 用途 |
| --- | --- |
| `series-variety.png` | 12 位角色的发型、姿态、表情与系列变化 |
| `theme-variety.png` | 不同主题的造型与色彩关系 |
| `apple-detail-reference.jpeg` | 苹果主题服饰的剪裁、纹样和细节组织 |
| `dark-palette-counterexample.png` | 深色聚团的配色反例，不作默认正向上色参考 |

参考图不是已通过本单全部质量要求的成品。具体借鉴与排除项见 [风格与参考](../../references/style-and-references.md)。公开可见不代表图片具有开放再授权许可。
