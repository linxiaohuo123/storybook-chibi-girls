# 参考图来源与用途

该目录包含来自用户对话的四张 Q 版少女插画视觉参考图，经过缩放及 WebP 有损压缩，仅供建立画风约束。保留在公共仓库不意味着图片已获开放许可。

- `series-variety.webp`：12 位角色的发型、姿态、表情、系列一致性。
- `theme-variety.webp`：不同故事主题和色彩搭配。
- `apple-detail-reference.webp`：苹果角色服装、道具、干净棕色细线。
- `dark-palette-counterexample.webp`：过暗配色的反例，避免直接继承。

完整的风格采用与禁忌请阅读 `../../references/style-and-references.md`。
